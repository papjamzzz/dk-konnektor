# DK Konnektor

**DraftKings DFS edge detector for PGA Tour golf.**

Four-signal scoring engine · Lineup optimizer · Dark-theme machine UI

---

## What It Does

Scores PGA Tour players using four signals and surfaces the ones with the highest DFS edge. Same machine aesthetic as Kalshi Konnektor — built for golf.

---

## Signal Engine

| Signal | Weight |
|--------|--------|
| Divergence (market vs. model) | 35% |
| Value (salary vs. projected points) | 30% |
| Course fit | 25% |
| Ownership projection | 10% |
